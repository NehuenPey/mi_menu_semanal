# Mi Menú Semanal

Primera versión de una app sencilla para anotar qué se comerá de lunes a domingo, al mediodía y a la noche.

## Funciones
- Vista semanal con los siete días.
- Agregar, editar y borrar comidas.
- Navegar entre semanas.
- Guardado local en el navegador.
- Diseño adaptable a Android y pantallas grandes.
- Base de PWA para instalarla cuando se publique en un sitio HTTPS.

## Probar en la computadora
Abrí `index.html` en un navegador. Para probar la instalación PWA y el funcionamiento sin conexión, conviene servir la carpeta con un servidor local, por ejemplo con la extensión Live Server de Visual Studio Code.

## Instalar en Android
1. Publicá los archivos en un sitio HTTPS (por ejemplo, GitHub Pages).
2. Abrí la dirección en Chrome desde el celular.
3. Abrí el menú de Chrome y elegí **Instalar aplicación** o **Agregar a pantalla de inicio**.
4. Abrí el ícono de Mi Menú desde la pantalla de inicio.

## Importante
Las comidas se guardan en el almacenamiento del navegador de ese dispositivo. Si se borran los datos del navegador, se cambia de navegador o se cambia de celular, los menús no se trasladan automáticamente. Esta versión no tiene sincronización en la nube.
